# dead-reckoning recovery plan
# recovery file: part_RECOVERY.gcode (verbatim tail from original byte 128)
# envelope: gap 0.2 + 0.15 x speed 1 + margin 0.5 = 0.85 mm
# shifted frame: Z declared 0.85 above position_min -2
# warning: no reheat_park_x/y configured; parking at computed (40, 15), verified clear of the part bounding box — set an explicit park position
 1. [idle-timeout] disarm the idle timeout FIRST (its default M84 would clear all homed state)
      send: SET_IDLE_TIMEOUT TIMEOUT=86400
      ok?:  idle_timeout.idle_timeout within 0.5 of 86400
      fail: abort (idle-timeout-not-applied)
 2. [stepper-enable] energize the Z steppers (enabling never touches homed state; there is no M17)
      send: SET_STEPPER_ENABLE STEPPER=stepper_z ENABLE=1
      send: SET_STEPPER_ENABLE STEPPER=stepper_z1 ENABLE=1
      ok?:  stepper_enable.steppers.stepper_z is true
      ok?:  stepper_enable.steppers.stepper_z1 is true
      fail: abort (stepper-enable-failed)
 3. [immediate-bed-heat] FIRST heating action (non-blocking): bed toward target (the long pole) + nozzle toward the clamped probe temp
      send: M140 S60
      send: M104 S145
      ok?:  heater_bed.target within 1 of 60
      ok?:  extruder.target within 1 of 145
      fail: abort (immediate-bed-heat-failed)
 4. [believed-z-declare] declare the conservative believed Z (possible-stop upper bound) then lift before XY homing
      send: SET_KINEMATIC_POSITION Z=0.4
      send: G91
      send: G1 Z5 F6000
      send: G90
      ok?:  toolhead.homed_axes contains "z"
      ok?:  toolhead.position.2 within 0.05 of 5.4
      fail: abort (believed-z-declare-failed)
 5. [home-xy] home XY only (never bare G28, never Z: the bed rises into a fixed gantry)
      send: G28 X Y
      ok?:  toolhead.homed_axes contains "x"
      ok?:  toolhead.homed_axes contains "y"
      fail: abort (homing-failed)
 6. [clean-nozzle] call the clean-nozzle macro (semantics unknowable; not verified)
      send: CLEAN_NOZZLE
      fail: abort (clean-nozzle-failed)
 7. [shifted-frame] declare the shifted frame: Klipper's rail limit now structurally bounds the descent
      send: SET_KINEMATIC_POSITION Z=-1.15
      ok?:  toolhead.homed_axes contains "z"
      ok?:  toolhead.position.2 within 0.05 of -1.15
      fail: abort (shifted-frame-not-declared)
 8. [probe-approach] XY travel to the selected contact point (no Z motion)
      send: G90
      send: G0 X20 Y10 F6000
      ok?:  toolhead.position.0 within 0.25 of 20
      ok?:  toolhead.position.1 within 0.25 of 10
      fail: abort (approach-failed)
 9. [accel-clamp] clamp max_accel to the touch accel around the consensus touch (restored after / on abort)
      send: SET_VELOCITY_LIMIT ACCEL=100
      ok?:  toolhead.max_accel within 1 of 100
      undo: SET_VELOCITY_LIMIT ACCEL={restore_accel}
      fail: abort (accel-clamp-failed)
10. [probe] consensus multi-touch (PLR_TOUCH: sliding-window best subset; median is the trigger Z)
      pre:  extruder.temperature in [140, 152] C
      pre:  extruder.target <= 150
      pre:  toolhead.homed_axes contains "x"
      pre:  toolhead.homed_axes contains "y"
      pre:  toolhead.homed_axes contains "z"
      send: PLR_TOUCH SAMPLES=3 SAMPLE_RANGE=0.01 SPEED=1 RETRACT=2 TOUCH_ACCEL=100
      ok?:  plr.last_touch_result.range <= 0.01
      ok?:  plr.last_touch_result.samples_used >= 3
      ok?:  plr.last_touch_result.median_z present and finite
      fail: abort (probe-no-trigger)
11. [accel-restore] restore the pre-clamp max_accel on the success path
      send: SET_VELOCITY_LIMIT ACCEL={restore_accel}
      ok?:  toolhead.max_accel within 1 of the step's computed value
      fail: abort (accel-restore-failed)
12. [true-z-declare] true-Z arithmetic and kinematic re-declaration (never a gcode offset)
      send: SET_KINEMATIC_POSITION Z={true_z}
      ok?:  toolhead.position.2 within 0.05 of the step's computed value
      fail: abort (true-z-declare-failed)
13. [final-declare] final true-frame declaration after all transforms are in place
      send: SET_KINEMATIC_POSITION Z={true_z}
      ok?:  toolhead.homed_axes contains "z"
      ok?:  toolhead.position.2 within 0.05 of the step's computed value
      fail: abort (final-declare-failed)
14. [park-for-reheat] lift off the part (rail-clamped) and park at the reheat XY (the file reheats to print temp here)
      send: G90
      send: G1 Z{park_z} F1200
      send: G0 X40 Y15 F6000
      ok?:  toolhead.position.0 within 0.25 of 40
      ok?:  toolhead.position.1 within 0.25 of 15
      ok?:  toolhead.position.2 within 0.05 of the step's computed value
      fail: abort (park-for-reheat-failed)
15. [restore-frame] replay offsets, speed/extrude factors, skew, fans (print temps reheat in the file)
      send: SET_GCODE_OFFSET X=0 Y=0 Z=0.05
      send: M220 S100
      send: M221 S100
      send: M106 S128
      ok?:  gcode_move.speed_factor within 0.01 of 1
      ok?:  gcode_move.extrude_factor within 0.01 of 1
      fail: abort (restore-failed)
16. [recovery-file-select] select the generated recovery file (M23), restore exclude-object state, start it (M24)
      send: M23 part_RECOVERY.gcode
      send: M24
      ok?:  virtual_sdcard.is_active is true
      ok?:  idle_timeout.state equals "Printing"
      fail: abort (recovery-file-select-failed)
