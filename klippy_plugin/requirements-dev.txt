# Dev/test dependencies for the klippy plugin gates (lint + tests +
# coverage).  Exact pins so the pre-commit hook, CI, and developers run
# identical tools; installed into .venv by scripts/setup-py.sh and
# directly by the CI python job.
#
# Pins resolved 2026-07-23 as the newest releases still supporting
# Python 3.9 (the dev-tooling floor and the older CI matrix leg):
# pytest 9.x and coverage >=7.11 require Python >=3.10, so they are
# deliberately NOT used.  Bump all four together and keep the 3.9 CI leg
# green.
#
# These are DEV deps only — the plugin's runtime deps inside klippy are
# exclusively what klippy already ships with (numpy optional, handled by
# plr.setup_checks.require_numpy).
pytest==8.4.2
pytest-cov==7.1.0
coverage==7.10.7
ruff==0.16.0
# numpy is a DEV dep only so the classifier's numpy path can be tested
# against its pure-python fallback (plr/classifier.py); at runtime numpy
# stays optional inside klippy.  No single numpy pin covers the whole
# dev range: 2.0.x is the last line supporting Python 3.9 (the tooling
# floor) but ships no 3.13 wheels, and 2.2.x ships no 3.14 wheels
# (cp314 wheels start at numpy 2.3.3), hence the three-way split by
# interpreter.  numpy 2.5.1 is the newest release with cp314 wheels as
# of 2026-07-24.
numpy==2.0.2 ; python_version < "3.13"
numpy==2.2.6 ; python_version == "3.13"
numpy==2.5.1 ; python_version >= "3.14"
